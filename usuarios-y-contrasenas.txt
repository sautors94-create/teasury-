==========================================================================
 USUARIOS Y CONTRASEÑAS — SISTEMA INTEGRAL DE TESORERÍA
==========================================================================

REGLA GENERAL: la contraseña de cada usuario es IGUAL a su nombre de
usuario (así se crean en el sistema: backend/src/db.ts, línea "Password
por defecto igual al username").

Ejemplo: usuario "admin"  ->  contraseña "admin"
         usuario "operador3"  ->  contraseña "operador3"

--------------------------------------------------------------------------
3) NOTAS IMPORTANTES
--------------------------------------------------------------------------

- Si dentro de la app cambiaste la contraseña de algún usuario (módulo de
  usuarios, con sesión de admin), esa contraseña ya NO es igual al
  usuario: usa la que hayas capturado. Esta lista refleja las claves
  POR DEFECTO con las que nace el sistema.
- Estas claves son para pruebas y uso interno. Antes de usar el sistema
  en producción, cambia las contraseñas desde el módulo de usuarios.
- Para volver a ver esta lista en cualquier momento también puedes abrir
  la base de datos: backend/data/tesoreria.db, tabla "usuarios" (ahí se
  guarda la contraseña cifrada, no en texto plano).
