      - LIMPIAR CATÁLOGO: nuevo botón rojo “Limpiar catálogo

── NOVEDADES DE LA VERSIÓN ANTERIOR (v9) ──────────────────────

  · CARGOS DE TESORERÍA — FUNCIONES ASIGNABLES A LAS PERSONAS
    Las funciones de la Tesorería (validador, altas, confirmador,
    fondeador) ya no son “puestos rígidos”: son CARGOS que se
    asignan al personal con casillas de verificación.
      - TODOS SON TESOREROS: una persona es tesorero y puede
        tener 1 o más cargos a la vez (p. ej. Fondeador +
        Confirmador), y un mismo cargo puede asignarse a
        varias personas (basta marcar la misma columna en
        varias filas).
      - NUEVA SECCIÓN “CARGOS” en el menú (la ven el
        Administrador y el Admin de Tesorería): tabla del
        personal de Tesorería con UNA COLUMNA DE CASILLAS por
        cargo — Validador | Altas | Confirmador | Fondeador —
        y botón “Guardar” por persona cuando hay cambios.
      - EL CARGO DA LAS MISMAS FUNCIONES QUE SU ROL
        EQUIVALENTE: con el cargo Fondeador la persona ve el
        menú Fondeo, ve el plan de flujos y puede LIBERAR
        operaciones; con Altas puede resolver altas bancarias
        y portales; con Confirmador entra a Confirmación de
        depósitos; con Validador entra a Tesorería con visión
        completa.
      - EN EL ALTA DE USUARIO (Usuarios, admin) también se
        pueden marcar los cargos al crear un tesorero.
      - La barra lateral muestra el nombre del rol y CHIPS con
        los cargos de la persona; la pantalla Usuarios también
        lista los cargos de cada uno.
      - Detalle técnico: los cargos viajan en la sesión; la
        persona afectada debe CERRAR SESIÓN Y VOLVER A ENTRAR
        para cargar sus cargos nuevos. Cada cambio queda en la
        bitácora de Auditoría (usuario_cargos). Migración
        automática: las bases existentes ganan la columna y el
        cargo natural de cada rol (val_tesoreria→validador,
        confirmador→confirmador, fondeador→fondeador,
        altas→altas).

── NOVEDADES DE LA VERSIÓN ANTERIOR (v6) ──────────────────────

  · COMPROBANTES: AHORA SÍ SUBEN. Se admiten TODOS los formatos
    (PDF, imágenes, XML de CFDI, hojas de cálculo, etc.) excepto
    .DOC. Antes el selector sólo ofrecía PDF e imágenes: los
    demás archivos aparecían en gris y no se podían elegir SIN
    NINGÚN MENSAJE — era la causa de "no me permite y no veo
    error". Ahora, si un archivo .DOC o mayor a 6 MB se rechaza,
    ves el motivo con claridad. Además se corrigió el backend:
    el límite interno de la API (100 KB) rechazaba en silencio
    casi cualquier comprobante real.
  · CUENTAS: SOLO EL ADMIN TESO AGREGA. El formulario "Nueva
    cuenta" y el cargador de cuentas ya no aparecen al resto de
    Tesorería (tesoreros, validador_tesoreria, etc.): ellos sólo
    consultan y operan las cuentas que les corresponden.
  · LAYOUT DE CUENTAS (4 columnas). En Cuentas, el Administrador
    de Tesorería ahora tiene "Cargar cuentas (layout)":
      - "Descargar layout" baja la plantilla con las columnas
        BANCO, NOMBRE, CLAVE (la CLABE a 18 dígitos) y
        CUENTA CORTA (número de cuenta).
      - "Cargar layout (Excel/CSV)" sube el archivo lleno y
        crea las cuentas; si una ya existe (misma CLABE o mismo
        banco + cuenta corta) la ACTUALIZA en vez de duplicarla.
        Acepta los encabezados en cualquier orden y alias
        (CLAVE = CLABE). Consejo: escribe las columnas de
        números como TEXTO en Excel para que no se pierdan
        ceros a la izquierda.
      - El pegado avanzado de 8 columnas sigue disponible abajo.

── PASO 1. Instalar Node.js (solo la primera vez) ──────────────

  1. Entra a https://nodejs.org
  2. Descarga la versión LTS (botón verde grande)
  3. Instálala con todo "Siguiente" (deja las opciones por defecto)
  4. Para verificar: abre PowerShell y escribe  node --version
     Debe responder v20 o superior.


── PASO 2. Descomprimir el proyecto ────────────────────────────

  1. Haz clic derecho sobre el zip → "Extraer todo..."
  2. Destino sugerido:  C:\tesoreria
  3. Quedará la carpeta con backend, desktop, docs, etc. adentro.


── PASO 3. Instalar las dependencias (solo la primera vez) ─────

  1. Abre PowerShell en la carpeta del proyecto:
     - Entra a C:\tesoreria en el Explorador
     - Escribe "powershell" en la barra de direcciones y Enter
  2. Ejecuta:
        npm install
     (una sola vez; instala backend + desktop juntos, tarda varios
      minutos, es normal ver muchas líneas amarillas/warnings)


── PASO 4. Arrancar el sistema ─────────────────────────────────

  Desde la misma carpeta, ejecuta:
        npm run dev

  Esto abre dos procesos a la vez:
   • api   (azul)  → la API en http://localhost:4000
   • web   (verde) → la interfaz en http://localhost:5173

  Abre en tu navegador:  http://localhost:5173

  Versión escritorio (Electron, opcional):
        npm run dev:app -w @teasury/desktop


── PASO 5. Base de datos ───────────────────────────────────────

  • Se crea sola en  backend\data\tesoreria.db  al primer arranque
    (no necesitas hacer nada).
  • La carpeta backend/data/ y los .db NO se suben a git ni vienen
    en el zip: son tus datos locales.
  • Para reiniciar la base con datos de prueba desde cero (borra
    todo lo capturado):
        cd backend
        npx tsx scripts/reiniciar-datos-pruebas.ts
  • Respaldo: basta copiar el archivo tesoreria.db a otro lugar.


── PASO 6. Verificar que todo está bien ────────────────────────

        npm test        → corre las pruebas de todas las fases
        npm run typecheck → valida tipos TypeScript


── GIT (para seguir trabajando entre dos PCs) ──────────────────

  Este zip YA incluye la carpeta .git con todo el historial, así
  que puedes continuar donde quedó:

        git status
        git log --oneline

  Si usas tu kit de GitHub (01-PRIMERA-VEZ-PC-NUEVO.bat ya no es
  necesario aquí porque .git viene incluido): conéctalo a tu repo
  remoto y haz git pull / git push como siempre.


── PROBLEMAS FRECUENTES ────────────────────────────────────────

  • "npm no se reconoce..."    → Node.js no quedó en el PATH;
    reinstálalo marcando la casilla por defecto y ABRE un
    PowerShell nuevo.
  • Error al compilar better-sqlite3 → falta Visual Studio Build
    Tools; instala "Windows Build Tools": npm i -g windows-build-tools
    o instala VS Build Tools C++ desde visualstudio.microsoft.com.
  • Puerto 4000 ocupado → cierra otra instancia o cambia el
    puerto:  $env:PORT=4010; npm run dev
  • Electron no abre → primero deja corriendo "npm run dev" en una
    ventana y usa dev:app en otra.
