Este zip contiene TODO el proyecto:
  backend/          API Node.js + TypeScript + SQLite (puerto 4000)
  desktop/          App de escritorio React + Vite (+ Electron)
  docs/             Toda la documentación (visión, operaciones, fases)
  scripts/          Smoke tests
  .git/             Historial completo de Git (todas las fases)
  schema.sql        Esquema de la base de datos central
  LEEME-FASE15.txt  Instrucciones de la fase más reciente (altas portales + bóveda)
  package-lock.json Versiones fijadas para reproducción exacta

IMPORTANTE: node_modules NO viene incluido (pesa 436 MB y se
regenera automáticamente con un solo comando, ver paso 3).


── NOVEDADES DE ESTA VERSIÓN (v4) ─────────────────────────────

  · NUEVA CAPTURA "NUEVA OPERACIÓN" = FORMATO DE OPERACIONES
    (idéntico al Excel del negocio; se quitó el formulario anterior):
      - Barra verde FORMATO DE OPERACIONES con el Folio Ops (se
        asigna al guardar).
      - Sección A: Fecha de la operación, Fecha del depósito,
        Empresa frente (RESGUARDO o frentes del catálogo), Banco
        del depósito y Monto Pagado.
      - Sección B: Cliente, Razón Social, RFC, Ejecutivo (tú) y
        Broker 1..4 con su % (montos calculados).
      - Sección C: Pagadora (catálogo o CUALQUIER FLUJO), Tipo de
        Operación FLUJOS, Timbrar y Comisión % (aviso rojo
        "COMISIÓN COBRADA EN RESGUARDO" cuando aplica).
      - Sección D: Monto Pagado, IVA, Neto, Comisiones (op y por
        broker), Resguardo, Devolución y Flujo Total — todos
        calculados en vivo.
      - DISPERSIÓN: tabla con los encabezados del formato
        (CONCEPTO, TIPO DE OPERACIÓN, PATERNO, MATERNO, NOMBRE,
        NOMBRE completo —se rellena solo al teclear paterno/
        materno/nombre—, REFERENCIA, RFC, INE, #, Tarjeta,
        CUENTA CLABE, Banco, CLABE, Importe). Se agregan filas
        con "+ Agregar fila" o importando el layout (Excel/CSV).
      - Barra azul de COMPROBACIÓN: Total, VERDADERO/FALSO y
        DIFERENCIA A FAVOR / (EN CONTRA), con la entidad de
        comprobación editable (MGN INTRUST por omisión).
      - Observaciones o Instrucciones Especiales.
      - La comprobación debe dar VERDADERO para guardar: el Flujo
        Total no puede exceder el Monto Pagado (regla del negocio).
  · NUEVO CAMPO RFC en las dispersiones (columna del formato): se
    guarda en la base (migración automática) y viaja con la
    operación; también se acepta por layout (encabezado RFC).
  · El botón "Pago especial (formato adjunto)" (fase 14) queda en
    la esquina de la barra verde.

── NOVEDADES DE ESTA VERSIÓN (v3) ─────────────────────────────

  · RESGUARDO TRF — REGLAS DEL NEGOCIO:
      - El ejecutivo de Operaciones (rol "operacion") YA NO VE el
        Resguardo de TRF: no aparece en su barra lateral y la API
        le responde 403 si pide el detalle/movimientos.
      - El resguardo ya NO se edita a mano: sólo se modifica al
        REGISTRAR una operación desde él (pago especial con origen
        TRF, comisión TRF de los flujos).
      - El efecto se aplica AL AUTORIZARSE la operación (Validación
        o Dirección): el retiro del pago especial y el ingreso de
        la comisión entran entonces al resguardo. Si el retiro no
        tiene fondo, la autorización NO procede (error 409).
      - Si una operación ya autorizada se CANCELA, sus movimientos
        se reversan automáticamente (ledger append-only).
      - Ajustes manuales del resguardo: sólo el admin (correcciones).
  · BARRA LATERAL FIJA: la marca, el menú y el bloque de usuario
    con "Cerrar sesión" ya NO se van con el scroll. La barra ocupa
    siempre el alto de la ventana; si el menú no cabe, sólo el menú
    hace scroll y "Cerrar sesión" queda fijo abajo.
  · MATRIZ TIPO EXCEL (fase 15.1) y ALTAS BANCARIAS para todos los
    roles (igual que la versión anterior, incluidas aquí).

── PASO 1. Instalar Node.js (solo la primera vez) ──────────────

  1. Entra a https://nodejs.org
  2. Descarga la versión LTS (botón verde grande)
  3. Instálala con todo "Siguiente" (deja las opciones por defecto)
  4. Para verificar: abre PowerShell y escribe  node --version
     Debe responder v20 o superior.


── PASO 2. Descomprimir el proyecto ────────────────────────────

  1. Haz clic derecho sobre el zip → "Extraer todo..."
  2. Destino sugerido:  C:\tesoreria
  3. Quedará la carpeta con backend, desktop, docs, etc. adentro.


── PASO 3. Instalar las dependencias (solo la primera vez) ─────

  1. Abre PowerShell en la carpeta del proyecto:
     - Entra a C:\tesoreria en el Explorador
     - Escribe "powershell" en la barra de direcciones y Enter
  2. Ejecuta:
        npm install
     (una sola vez; instala backend + desktop juntos, tarda varios
      minutos, es normal ver muchas líneas amarillas/warnings)


── PASO 4. Arrancar el sistema ─────────────────────────────────

  Desde la misma carpeta, ejecuta:
        npm run dev

  Esto abre dos procesos a la vez:
   • api   (azul)  → la API en http://localhost:4000
   • web   (verde) → la interfaz en http://localhost:5173

  Abre en tu navegador:  http://localhost:5173

  Versión escritorio (Electron, opcional):
        npm run dev:app -w @teasury/desktop


── PASO 5. Base de datos ───────────────────────────────────────

  • Se crea sola en  backend\data\tesoreria.db  al primer arranque
    (no necesitas hacer nada).
  • La carpeta backend/data/ y los .db NO se suben a git ni vienen
    en el zip: son tus datos locales.
  • Para reiniciar la base con datos de prueba desde cero (borra
    todo lo capturado):
        cd backend
        npx tsx scripts/reiniciar-datos-pruebas.ts
  • Respaldo: basta copiar el archivo tesoreria.db a otro lugar.


── PASO 6. Verificar que todo está bien ────────────────────────

        npm test        → corre las pruebas de todas las fases
        npm run typecheck → valida tipos TypeScript


── GIT (para seguir trabajando entre dos PCs) ──────────────────

  Este zip YA incluye la carpeta .git con todo el historial, así
  que puedes continuar donde quedó:

        git status
        git log --oneline

  Si usas tu kit de GitHub (01-PRIMERA-VEZ-PC-NUEVO.bat ya no es
  necesario aquí porque .git viene incluido): conéctalo a tu repo
  remoto y haz git pull / git push como siempre.


── PROBLEMAS FRECUENTES ────────────────────────────────────────

  • "npm no se reconoce..."    → Node.js no quedó en el PATH;
    reinstálalo marcando la casilla por defecto y ABRE un
    PowerShell nuevo.
  • Error al compilar better-sqlite3 → falta Visual Studio Build
    Tools; instala "Windows Build Tools": npm i -g windows-build-tools
    o instala VS Build Tools C++ desde visualstudio.microsoft.com.
  • Puerto 4000 ocupado → cierra otra instancia o cambia el
    puerto:  $env:PORT=4010; npm run dev
  • Electron no abre → primero deja corriendo "npm run dev" en una
    ventana y usa dev:app en otra.
